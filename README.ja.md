# LocalSend Go ライブラリ & CLI (日本語版)

LocalSendプロトコル（v2.1）をGo言語で実装したライブラリ、およびコマンドラインツール（CLI）のプロジェクトです。

> [!WARNING]
> **免責事項**: 本プロジェクトは LocalSend プロトコルの**非公式**コミュニティ実装です。公式の LocalSend プロジェクトとは一切関係がなく、保守・サポートも公式とは独立して行われています。

## 概要

本プロジェクトは、ローカルネットワーク内で安全かつ簡単にファイルを送受信するツール「LocalSend」のコアプロトコルをGoで再実装し、以下の価値を提供することを目指します。

1. **Goライブラリ**: 外部ライブラリへの依存を最小限に抑え、任意のGoプロジェクトに組み込み可能なLocalSend通信モジュール。
2. **多言語対応CLI**: 端末上で動作する、英語・日本語対応の軽量なコマンドラインインターフェース。
3. **デバッグ性の向上**: 開発・検証向けに、プロキシ設定やカスタム証明書のロード、自己署名証明書の検証スキップなどのオプションを標準サポート。

---

## 主な特徴と本家（公式）との違い

- **1IPアドレスにおける複数アプリ動作の対応**:
  公式の LocalSend クライアントは周辺デバイスを IP アドレスのみで管理するため、同一ホスト上で競合が発生（デバイス情報が上書き）しますが、本実装では **`IP:Port` をキーとして管理** します。ポート 53317 から最大 10 個まで空きポートを自動探索してバインドするため、同一PC上で複数の LocalSend クライアントを同時に起動し、互いに通信させることができます。
- **公式アプリとの相互運用性**:
  ポートを自動シフトする拡張を行っていますが、ローカルネットワーク上の本家公式アプリ（デスクトップ・モバイル）とも完全に互換性があり、問題なくファイルを送受信できます。
- **HTTPS サーバー機能の制限**:
  現状、ブラウザ共有モード（Webshare）や一部ローカル受信 API において HTTPS サーバーとしての動作は非対応、または制限されており、主にシンプルな HTTP で動作します。
- **デバッグ・開発サポート (CLI)**:
  `--proxy` オプションや `-k / --insecure` オプション（証明書検証のスキップ）を実装し、Mitmproxy等でのパケット解析や検証を容易にします。
- **依存の最小化**:
  ライブラリ部分 (`pkg/`) はGo標準ライブラリを最大限に活かし、軽量かつ安全にビルド可能です。
